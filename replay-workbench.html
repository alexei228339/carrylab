♢ CARRYLAB 1.0 · WINDOWS + WEB

Реплейная мастерская, господин ♡

Скачивайте доступные файлы Dota 2 на своём Windows-компьютере и смотрите результаты прямо на CarryLab. Не нужно загружать реплеи на чужой сервер.

1. Скачать локальный помощник

Откройте папку windows-helper и скачайте два файла: replay_helper.py и start.bat в одну папку на ПК.

Файлы помощника в GitHub ↗

Нужен Python 3.10+; установка дополнительных библиотек не требуется.

2. Запустить

Дважды нажмите start.bat, введите ID матча. Программа попробует скачать доступный .dem.bz2 и распаковать его в .dem.

Если у Valve запись уже удалена или OpenDota не знает её параметров, скачать её нельзя.

3. Импорт результатов на сайт

Выберите JSON-файл. Помощник пока создаёт только *-manifest.json со статусом скачивания. Чтобы показать путь игрока, нужен JSON с массивом positions: [{x, y, time}] от настоящего парсера.

Господин, файл читается только вашим браузером.



Какие данные доступны сейчас?
✓ Загрузка доступного реплея по ID через локальный Python. ✓ Распаковка .bz2. ✓ Импорт JSON и отображение координат. ✕ Автоматическое извлечение маршрута из .dem — ещё не готово.
Следующий инженерный этап — интеграция Clarity или другого парсера Dota 2, извлечение позиций героев и построение таймлайна.
