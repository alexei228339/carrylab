Два игрока на одном герое

Введи Steam32 ID обоих игроков и выбери героя. Сравниваются последние доступные матчи на этом герое; статус профессионального игрока не подтверждается автоматически.

Загрузить разобранные данные

Поддерживается JSON с поминутными координатами positions и временем time. Оригинальный .dem не обрабатывается в браузере.

Состояние обработки

Для автоматического анализа .dem нужен отдельный сервер с парсером реплеев. GitHub Pages умеет показывать только уже разобранные данные.

Данные из произвольных JSON проверяются локально; файл не отправляется на сервер CarryLab.

Визуализация последовательности координат

Упрощённая координатная сетка — не изображение игровой карты. Требуется правильная система координат исходного парсера.
